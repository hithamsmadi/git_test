# Bau Logistics

This repository contains a prototype for **Bau Logistics**, a role-based construction workforce and site management system for Germany-based operations.

```
bau-logistics/
├── client/   # React + TypeScript frontend
├── server/   # Node.js + Express backend
├── prisma/   # Prisma schema
```

The project uses JWT authentication and middleware-based RBAC.
Credentials are created by admins and stored in the database.
